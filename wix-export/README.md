# Intelekta Skola — Wix Editor Content Pack

This folder contains **copy-paste ready content** for rebuilding the site in [Wix](https://www.wix.com).

Primary language: **Latvian (LV)**. English and Russian strings are noted where useful for Wix Multilingual.

---

## How to use in Wix

1. **Create pages** in Wix (left panel → Pages & Menu) using the names and slugs in `00-site-structure.md`.
2. **Open each `.md` file** in this folder — one file = one Wix page.
3. For each **SECTION**, add a Wix strip/section and paste text into Text, Heading, or Button elements.
4. **Upload images** listed in `09-images-and-links.md` via Media Manager.
5. **Set menu links** to your Wix page URLs (not `.html` paths).
6. **Contact form:** use Wix Forms or Wix Contacts — field labels are in `06-contact.md`.
7. **Stripe buttons:** add Button → Link to URL (payment links in `09-images-and-links.md`).
8. **FAQ page:** use Wix FAQ element or Accordion — copy Q&A pairs from `05-faq.md`.
